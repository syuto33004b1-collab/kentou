# 鍵闘 KENTOU

格ゲー風のタイピング練習サイト。日本語のお題をローマ字で打ち切るたびに、
一撃がCPUに入る。打鍵1回の手応えと、打ち切った瞬間の爆発を別に設計している。

**▶ https://syuto33004b1-collab.github.io/kentou/**

## 遊び方

1. タイトル画面で `1` / `2` / `3` を押して難易度を選ぶ
2. 表示された漢字の読みをローマ字で打つ（`波動拳` → `hadouken`）
3. お題を1つ打ち切ると相手に一撃。速く・ノーミス・コンボが乗ると威力が上がる
4. 残り時間が切れると相手の攻撃。ミスタイプはコンボが切れて小ダメージ
5. 先に体力を0にした方がKO。`R` でもう一戦、`Esc` で難易度選択に戻る

| 難易度 | CPUの速度 |
|---|---|
| 修行 / TRAINING | 110 KPM |
| 闘士 / FIGHTER | 190 KPM |
| 鬼 / DEMON | 290 KPM |

## 入力について

日本語IMEはOFFで、直接ローマ字を打つ。訓令式・ヘボン式のどちらでも受理する。

- `し` → `shi` / `si` / `ci`
- `つ` → `tsu` / `tu`
- `じゃ` → `ja` / `jya` / `zya`
- `っ` → 子音重ね（`せっか` → `sekka`）または `xtu` / `ltu`
- `ん` → 後続が子音なら `n` 単独でよい。母音・な行・や行の前と語末は `nn` / `n'` / `xn`
- `ん` を `n` 単独で確定した直後の追加 `n` は、IMEと同じく飲み込む

## 構成

ビルド工程なし。素のHTML/CSS/ESモジュールだけで動く。

```
index.html
style.css
src/romaji.js       かな列→ローマ字入力の受理オートマトン
src/romaji.test.js  上記のテスト
src/words.js        お題データ（技名・格ゲー用語・実況セリフ）
src/fx.js           Canvasパーティクル・画面シェイク・ヒットストップ
src/sound.js        Web Audio APIによる合成SE（音源ファイルなし）
src/game.js         状態機械と戦闘計算
```

外部素材・外部ライブラリはゼロ。キャラクターはSVG、エフェクトはCanvas、
SEはすべてWeb Audio APIでその場で合成している。

## 開発

```bash
python -m http.server 5173
```

`http://127.0.0.1:5173/` を開く（ESモジュールを使うので `file://` では動かない）。

テストはローマ字判定エンジンにだけ置いている。全98お題が破綴なくトークン化でき、
表示したガイドどおりに打ち切れることまで検証する。

```bash
node src/romaji.test.js
```

## アクセシビリティ

- `prefers-reduced-motion: reduce` でシェイク・フラッシュ・パーティクルを停止する。
  ヒットストップとダメージ数値は残すので、ゲームとしての手応えは変わらない
- 全画面フラッシュは不透明度0.35までに制限し、点滅を繰り返さない
- 音のON/OFFトグルを常設

設計の詳細は [docs/superpowers/specs/2026-09-03-kentou-design.md](docs/superpowers/specs/2026-09-03-kentou-design.md) にある。
