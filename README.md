# 鍵闘 KENTOU

格ゲー風のタイピング練習サイト。日本語のお題をローマ字で打ち切るたびに、
一撃がCPUに入る。打鍵1回の手応えと、打ち切った瞬間の爆発を別に設計している。

**▶ https://syuto33004b1-collab.github.io/kentou/**

## 遊び方

日本語入力（IME）はOFF、半角英数にしてから始める。ONのままだと画面が警告を出す。

| キー | モード | CPUの速度 |
|---|---|---|
| `1` | 見習い / ROOKIE | 110 KPM |
| `2` | 闘士 / FIGHTER | 190 KPM |
| `3` | 鬼 / DEMON | 290 KPM |
| `4` | 修練 / TRAINING | 時間制限なし |

- **打ち切る＝攻撃**。速く・ノーミス・コンボが乗るほど威力が上がる
- **時間切れ＝被弾**。お題ごとの制限時間を切らすとCPUの攻撃が入る
- **ミス＝よろけ**。コンボが半減し、小ダメージを受ける
- 先に体力を0にした方がKO。`R` でもう一戦、`Esc` でモード選択に戻る
- 画面から離れる（タブ切り替え・ウィンドウのフォーカス外れ）と自動でポーズする

### 攻撃の階級

ダメージに応じて、ヒットストップ・打撃音・ノックバック距離・パーティクル量が
弱／中／強／必殺の4段で変わる。長いお題、ノーミス、高コンボが重なると必殺級になる。

- **COUNTER** — 残り時間が15%を切ってからの完打。ダメージ1.4倍
- 残り1〜2文字でキャラが踏み込む（予兆）。当たる前の溜めが打撃感の本体

### 修練モード

時間制限もCPUの攻撃もない。カテゴリ（技名／格ゲー用語／実況セリフ）と
長さ（短文／中文／長文）を選んで、苦手なところだけ反復できる。
打鍵数・正確率・KPMは打つたびに更新される。

### 記録

結果画面に**ミスが多いキー**のワースト5（まだミスが無ければ**打つのが遅いキー**）、
前回比、自己ベスト、通算成績が出る。すべてブラウザの localStorage に入るだけで、
どこにも送信しない。

## 入力について

訓令式・ヘボン式のどちらでも受理する。タイトル画面の「ローマ字の受理ルール」に
表がある。

- `し` → `shi` / `si` / `ci`
- `つ` → `tsu` / `tu`
- `じゃ` → `ja` / `jya` / `zya`
- `っ` → 子音重ね（`せっか` → `sekka`）または `xtu` / `ltu`
- `ん` → 後続が子音なら `n` 単独でよい。母音・な行・や行の前と語末は `nn` / `n'` / `xn`
- `ん` を `n` 単独で確定した直後の追加 `n` は、IMEと同じく飲み込む

## 構成

ビルド工程なし。素のHTML/CSS/ESモジュールだけで動く。外部素材・外部ライブラリはゼロ。
キャラクターはSVG、エフェクトはCanvas、SEはすべてWeb Audio APIでその場で合成している。

```
index.html
style.css
src/romaji.js       かな列→ローマ字入力の受理オートマトン
src/battle.js       戦闘の数値計算（ダメージ・COUNTER・階級）
src/words.js        お題データ（技名・格ゲー用語・実況セリフ）
src/stats.js        打鍵記録と苦手キー分析（localStorage）
src/fx.js           Canvasパーティクル・画面シェイク・ヒットストップ
src/sound.js        Web Audio APIによる合成SE
src/game.js         状態機械と画面制御
```

`romaji.js` / `battle.js` / `stats.js` / `words.js` は DOM を触らないので、
ブラウザなしで検証できる。`game.js` はそれらを画面と音に繋ぐだけ。

## 開発

```bash
python -m http.server 5173
```

`http://127.0.0.1:5173/` を開く（ESモジュールを使うので `file://` では動かない）。

テストは DOM を持たない4モジュールに置いている。フレームワークは使わず node の
`assert` だけ。

```bash
node src/romaji.test.js && node src/battle.test.js && node src/stats.test.js
```

- `romaji.test.js` — 拗音・促音・撥音の綴り分岐と、全108お題が表示ガイドどおりに
  打ち切れること
- `battle.test.js` — COUNTERの閾値と倍率、速度補正のクランプ、コンボ上限、
  「一戦で弱・中・強・必殺が順に出る」こと
- `stats.test.js` — 苦手キーの並び順、異常な打鍵間隔の除外、自己ベストの更新条件、
  カテゴリ×長さの全組み合わせが引けること

演出とレイアウトは自動テストの対象にしていない。実機で動かして確認する。

## アクセシビリティ

- `prefers-reduced-motion: reduce` でシェイク・フラッシュ・パーティクル・予兆を停止する。
  ヒットストップとダメージ数値は残すので、ゲームとしての手応えは変わらない
- 全画面フラッシュは不透明度0.35までに制限し、点滅を繰り返さない
- 音のON/OFFトグルを常設
- モードはクリック／タップでも選べる。ただし本体は物理キーボードが必要なので、
  タッチ環境ではその旨を表示する

設計は `docs/superpowers/specs/` にある。
